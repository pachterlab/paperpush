Privacy and data

This page covers the public website at paperpush.onrender.com. paperpush is open source (GitHub), so you can check everything said here in its code. If you would rather your files never leave your computer, install paperpush and run paperpush web. It serves this same page on your machine only.

Your uploaded files

  • Files you upload go into a workspace on the server's disk, named by a random 32-character ID. The page keeps that ID in your browser. Anyone who has the ID can read the workspace, and the site never shows or lists it to anyone else.
  • A workspace is deleted 24 hours after it was last used. The server checks every 15 minutes. Settings › Clear deletes it at once. Every redeploy also wipes the server's disk.
  • A workspace holds at most 200 MB. The files are read only to run the checks you ask for.
  • The site does not follow links or look up DOIs found in your files. Those checks run only in the installed version.

Your form (the .sub)

  • The form you fill in is kept in your browser's storage, not on the server. It is sent to the server only with a request that needs it (validate, autofill, download).
  • A share link carries the form inside the link itself, after the #. Browsers never send that part to a server, so nothing is stored.
  • Share for editing stores one copy for everyone with the link. Your browser encrypts it (AES-GCM) with a key that exists only in the link, after the #, and the server stores only the encrypted copy. Neither the site nor its database host can read it. Changing or deleting it takes a token derived from that key. A shared form nobody has saved for 90 days is deleted, and anyone with the link can delete it sooner.

Your API keys

  • The AI features use your own key (Anthropic, OpenAI, Google, Winston AI, Originality.ai, or Pangram). The key is sent only with the request that needs it and used only for that request. The server never stores it, and it is masked in any error message or report.
  • Your browser keeps the key for this tab only, unless you tick Remember API key on this device.

Which services see what

The website uses these services. The ones marked only if you ask receive data only when you use that feature with your own key.

Each AI and scanning service handles your data under its own terms for API customers, through your own account.

Logs, cookies, and tracking

  • paperpush logs events such as "workspace created" with only the first 6 characters of an ID, and it does not log individual requests. When something fails, the log can include the error message and a file name. Render's platform can record the address of each request it forwards, and those addresses include workspace IDs. Render keeps its logs under its own retention policy.
  • The site sets no cookies and has no analytics, ads, or trackers. Every script and font comes from this site.
