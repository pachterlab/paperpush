Add a venue

Describe a journal, preprint server, or conference that paperpush does not support yet, or correct one it does. This page writes a venue file. Download it, then run paperpush add-venue FILE to add the venue to your copy of paperpush, or attach the file to an issue to have it added for everyone. Record only what the venue's own pages say, and leave the rest empty.

Start from

1. Venue 2. Submission form 3. Author guidelines 4. Article types

1. Venue

General information, written to venues.json.

2. Submission form

The fields the portal asks for, in its order, written to submission_forms.json. They become the venue's .sub file. Untick to add a venue paperpush only checks manuscripts against, with no submission form.

Fields

Started from the fields most portals share. Remove those this portal lacks; reuse a listed id where one fits, so paperpush places it like other venues'.

3. Author guidelines

What the guidelines require of the manuscript itself, written to manuscript_requirements.json and checked by paperpush validate. These are the rules for a research article. Rules with no box of their own go in a section's notes, one sentence per line.
