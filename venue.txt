# paperpush venue file  -*- mode: yaml -*-
#
# Describes one venue (journal, preprint server, or conference) for paperpush.
# Fill it in, then add it with:   paperpush add-venue venue.txt
#
#   [venue]                       -> venues.json: the list of venues
#   [form], [field ID]            -> submission_forms.json: what the portal asks for
#   [requirements],
#   [requirements.SECTION],
#   [article_type NAME]           -> manuscript_requirements.json: what the author
#                                    guidelines require of the manuscript
#
# Syntax (the same as a .sub file): `key: value` on one line, or `key: |` followed by
# lines indented two spaces. Lists: comma-separated on one line, or one item per line
# in a `|` block. Booleans: yes / no. Leave a value empty when the venue does not say;
# empty keys are ignored. Lines starting with '#' are comments.
#
# Record only what the venue's own pages state. To fill it in with an AI agent: "Fill
# in venue.txt for <venue> from its submission portal and author guidelines."

# Field keys ([field ID] blocks; ID is the key used in the .sub file):
#   label: Human-readable prompt shown for the field
#   type: Widget/value kind: text | textarea | choice | multichoice | boolean | int |
#       file | filelist | authorlist
#   required: Whether submission requires a value (yes/no)
#   section: .sub template section the field is listed under, for an id paperpush does
#       not already place: type | files | metadata | authors | reviewers | declarations
#       | additional
#   help: Guidance shown alongside the field
#   options: Allowed values for `choice`/`multichoice` (list)
#   options_file: Name of a newline-separated keyword file under `venues/_assets/` whose
#       lines become this field's `options`
#   options_recommended: For a `choice`/`multichoice` field, whether `options` is
#       advisory (a value outside the list is a WARNING, not an ERROR) rather than a
#       closed set (yes/no)
#   default: Default value, written like the field's own value (yes/no for a boolean)
#   accept: Permitted file extensions for `file`/`filelist`, e.g. [".pdf", ".docx"]
#       (list)
#   fields: Sub-field (column) names for a structured multi-item field such as an
#       `authorlist` or a pipe-delimited `textarea` (funding, suggested reviewers)
#       (list)
#   type_options: Per-file 'file type' dropdown choices applied to this field's uploads
#       (list)
#   min_count: Inclusive lower bound on item count for a multi-item field (multichoice
#       selections, filelist/authorlist/list-textarea lines) (whole number)
#   max_count: Inclusive upper bound on item count for a multi-item field (whole number)
#   word_count: Maximum length in words for a `text`/`textarea` value (whole number)
#   character_count: Maximum length in characters for a `text`/`textarea` value, or for
#       the free text of a `choice` with `options_recommended` (whole number)
#   min_character_count: Minimum length in characters for a `text`/`textarea` value (the
#       lower-bound counterpart to `character_count`) (whole number)
#   require_url: For a `text`/`textarea`, require each non-blank line of the value to be
#       a valid http/https URL (yes/no)
#   max_words_before_refs: For a manuscript `file`, the maximum word count of the main
#       text before the reference list (whole number)
#   max_pages_before_refs: For a manuscript `file` (PDF), the maximum page count before
#       the reference list (whole number)
#   main_text_end_headings: For a manuscript `file`, headings *other than the reference
#       list* that end the main text for the `*_before_refs` limits (e.g. `Appendix`,
#       `Ethics Statement`) -- sections the venue excludes from its word/page count
#       (list)
#   max_words: For a manuscript `file`, the maximum word count of the whole document
#       (references included) (whole number)
#   max_pages: For a manuscript `file`, the maximum page count of the whole document
#       (whole number)
#   max_words_before_refs_by: `max_words_before_refs` selected by a sibling field's
#       value (e.g. by article type) (JSON)
#   max_pages_before_refs_by: `max_pages_before_refs` selected by a sibling field's
#       value (JSON)
#   max_words_by: `max_words` selected by a sibling field's value (JSON)
#   max_pages_by: `max_pages` selected by a sibling field's value (e.g (JSON)
#   min_value: Inclusive lower bound on the numeric value of an `int` field (whole
#       number)
#   max_value: Inclusive upper bound on the numeric value of an `int` field (whole
#       number)
#   max_file_size_mb: Maximum size, in megabytes, of each individual file uploaded for a
#       `file`/`filelist` field (number)
#   autofill: How an autofill engine may populate the field: extract | classify |
#       filemap | never
#   confirm: For a required `boolean`, whether it is a consent checkbox that must be
#       affirmative (vs. an informational yes/no question) (yes/no)
#   required_if: Id of another field in the same venue; when that field has a non-empty
#       value, this field becomes required
# Reuse a common id where one fits (abstract, acknowledgements, additional_datasets,

# competing_interests_statement, conflict_of_interest, corresponding_gender,
# cover_letter, data_availability, data_availability_links, data_availability_statement,
# ...): it is placed in the .sub automatically.
